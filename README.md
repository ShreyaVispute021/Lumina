# 💬 Lumina – Real-Time Chat Application

Lumina is a real-time chat application built using WebSocket technology that allows users to join chat rooms and exchange messages instantly. The app ensures seamless communication with live message updates without requiring page reloads.

---

## 🚀 Features

* 💬 Real-time messaging using WebSockets
* 👥 Join chat rooms and communicate instantly
* ⚡ Live updates without page refresh
* 🎯 Clean and minimal user interface
* 🌐 Full-stack implementation (Frontend + Backend)

---

## 🛠️ Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

### Real-Time Communication

* Socket.io (WebSocket library)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```id="5ex2vw"
git clone https://github.com/ShreyaVispute021/Lumina.git
cd Lumina
```

---

### 2️⃣ Install dependencies

```id="nfxf4h"
npm install
```

---

### 3️⃣ Run the server

```id="q31n87"
node server.js
```

## 🌐 Usage

1. Open your browser and go to:

```id="9q6c5z"
http://localhost:3000
```

2. Enter your username and join a chat room
3. Start sending and receiving messages in real-time 🎉
